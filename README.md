# 周数表 · EdgeEver 插件

在笔记软件中查看 ISO 8601 全年周次与日期范围，并将当前周数插入笔记。无需联网计算，无第三方运行时依赖。

## 使用

安装并启用插件后，在 EdgeEver 命令面板中运行：

- **打开周数表**：查询日期所属的周、切换年份或回到本周；点击任意周后复制或插入完整日期范围，也可插入周报模板。
- **插入当前周数**：先打开笔记并进入编辑状态，再将 `第N周（YYYY）` 插入光标位置。

周数表仅在列表内部滚动，表头保持可见。表格中的 `W01` 表示第 1 周；同年日期显示为 `MM.DD`，跨年日期保留完整年份。将鼠标放在日期上可查看完整日期。

## 周报格式与填写约定

点击「插入周报模板」，只在光标处插入以下空白板块：

```text
本周完成工作

下周工作计划

本周工作总结

需协调与帮助
```

模板不附带日期、周数、编号、图片或附件栏，也不预填工作成果或“无需协调”等结论。填写时使用正式简洁的语言，并遵守以下约定：

- 仅使用用户主动提供的真实工作信息，不补充未提及的任务、项目、成果、困难或协作需求。
- 周报全文不使用阿拉伯数字、中文数字、百分比、工时、条数、金额、进度占比、修改次数、工期、编号或指标数据；进度仅作定性描述。
- 「本周完成工作」描述实际工作动作与完成情况；「下周工作计划」仅依据用户提供的规划。
- 「本周工作总结」提炼有素材支持的收获、改善和客观阻碍；「需协调与帮助」仅依据用户提出的困难。
- 没有工作素材时，先收集本周完成事项、下周规划和现存难点，再撰写完整周报。

此功能仅插入空白结构，不自动生成或审核正文。「复制日期范围」「插入日期范围」与「插入当前周数」仍可单独使用。

## 周数规则

采用 ISO 8601：每周从周一开始，第 1 周包含 1 月 4 日，全年有 52 或 53 周。ISO 周年可能与公历年份不同，例如 2027 年 1 月 1 日属于 ISO 2026 年第 53 周。

## 安装与发布

在 EdgeEver 的插件安装入口填写仓库地址：

```text
https://github.com/ZhenYu-Jiang/edgeever-week-numbers
```

发布版本时，在 GitHub Release 中附加本仓库的 `manifest.json`、`main.js` 和 `styles.css` 三个文件，并确保发布版本与清单版本一致。

此版本把面板样式从 `main.js` 拆分到 `styles.css`，补齐 EdgeEver 安装所需的样式资产，其余保持不变。

- 当前周与日期范围摘要。
- 紧凑年份导航与键盘焦点提示。
